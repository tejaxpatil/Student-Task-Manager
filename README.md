# Student Task Manager

A React + Vite + TypeScript + Tailwind CSS frontend scaffold for the team's Software Project Management demonstration.

## Requirements
- Node.js LTS (with npm)
- Git

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Validate the build

```bash
npm run build
```
